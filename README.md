# Tab Limiter : Stop tab chaos!

- Take control of your browser tabs, stay focused, and boost productivity.

Do you find yourself opening dozens of tabs and losing track of what’s important? TabMaster helps you manage your tabs effortlessly by setting per-site and global tab limits, giving you notifications, and preventing tab overload — all without losing your content. 

## Features

* Per-Domain Limits: Set how many tabs can be open for each website.

* Global Tab Limit: Prevent too many tabs across all websites.

* Smart Notifications: Get alerts before tabs are closed.

* Modern, Responsive UI: Easy-to-use options page on both desktop and mobile.

* Works on Firefox & Chrome: Cross-browser support.
